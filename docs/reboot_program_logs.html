Reboot Programs and Log Reference

Startup services, responsibilities, and log patterns for CHATAK/ODAS runtime.

Reboot Startup Programs

User Crontab Helper Programs

  • @reboot record_odas.py: Manages passive audio recording.
  • @reboot cd /mnt/CHATAK_VM && python3 cors_http_server.py: Starts a browsable file server on flash storage.
  • @reboot /home/chatak/ChatakGUI/wifi_deamon.py: Scans and connects to known Wi-Fi networks.

Sudo Crontab USB + Mic Management

  • @reboot /usr/bin/python3 /home/chatak/ChatakGUI/asound_check.py: Verifies ReSpeaker and updates ALSA config.
  • @reboot /usr/bin/python3 /home/chatak/ChatakGUI/usb_mount.py: Ensures USB drive is mounted correctly.

ClassifierLogs

JSON output from the SST module, primarily used for building and testing workflows.

record_odas.py

Program: @reboot record_odas.py - passive recording manager.

Log Categories

  1. Startup and housekeeping (creates cronDDMMYY_HHMM.log, rotates old logs).
  2. Process checks (ODAS running check with odaslive and yammnetterminal_sensitive.cfg).
  3. Mount operations for /mnt/CHATAK_VM, including fsck and remount attempts.
  4. Recording events using record.txt and pause.txt.
  5. Sleep/wake cycle based on dynamic wake.txt and sleep.txt.
  6. Error handling with timestamped exceptions.

Example Entries

2026-07-24 16:47:12 - Recording with ODAS to /mnt/CHATAK_VM/Passive_Audio
2026-07-24 16:47:17 - CHATAK_VM not mounted. Skipping recording.
2026-07-24 16:47:22 - Device is sleeping
2026-07-24 16:47:25 - Mount failed after fsck: [error details]
2026-07-24 16:47:30 - Process check failed: [error details]

wifi_deamon.py

Program: @reboot wifi_deamon.py - Wi-Fi connectivity manager.

Log Categories

  1. Startup and housekeeping (wifi_daemonDDMMYY_HHMM.log + rotation).
  2. Connection status logs for connected/disconnected state.
  3. Network scanning and visible SSID reporting via nmcli.
  4. Profile management for known/added connections.
  5. Connection attempts and outcomes.
  6. wpa_supplicant.conf read/parsing errors.
  7. Daemon lifecycle stop events.

Example Entries

2026-07-24 16:51:03 - Found networks: HomeNet, OfficeWiFi
2026-07-24 16:51:03 - SSID HomeNet is in wpa_supplicant and visible.
2026-07-24 16:51:03 - Profile for HomeNet already exists, skipping add.
2026-07-24 16:51:03 - Attempting to bring up connection HomeNet...
2026-07-24 16:51:05 - Connected to HomeNet
2026-07-24 16:52:15 - Wi-Fi is connected to HomeNet

cors_http_server.py

Program: @reboot cors_http_server.py - serves /mnt/CHATAK_VM with CORS enabled.

Log Categories

  1. Startup bind message (0.0.0.0:8001).
  2. Request handling by CORSRequestHandler.
  3. Adds Access-Control-Allow-Origin: *.
  4. MIME fixes for .css and .js.
  5. Continuous lifecycle via httpd.serve_forever().

Example Entries

Serving HTTP on 0.0.0.0 port 8001, serving only /mnt/CHATAK_VM directory...
127.0.0.1 - - [24/Jul/2026 16:55:12] "GET /file.css HTTP/1.1" 200 -

asound_check.py

Program: @reboot asound_check.py - validates ALSA config for ReSpeaker.

Log Categories

  1. Startup and housekeeping (sudocronDDMMYY_HHMM.log + rotation).
  2. Device detection using arecord -l and matching ReSpeaker/ArrayUAC.
  3. Configuration update to /etc/asound.conf with pcm.multi_capture.
  4. Exception logging for cleanup, detection, or update failure.

Example Entries

2026-07-24 16:55:12 - ReSpeaker device not found in arecord -l output.
2026-07-24 16:55:18 - Updated /etc/asound.conf with hw:2,0
2026-07-24 16:55:20 - Could not delete sudocron240726_1645.log: [error details]

usb_mount.py

Program: @reboot usb_mount.py - ensures /mnt/CHATAK_VM is mounted and usable.

Log Categories

  1. Startup and housekeeping (sudocronDDMMYY_HHMM.log + rotation).
  2. Mount point creation/readiness for /mnt/CHATAK_VM.
  3. Device discovery from blkid /dev/sda1 (UUID and TYPE parsing).
  4. /etc/fstab add/check logic.
  5. Mount execution via mount -a.
  6. Exception logging across all mount pipeline steps.

Example Entries

2026-07-24 16:58:12 - Created mount point /mnt/CHATAK_VM
2026-07-24 16:58:13 - blkid output: /dev/sda1: UUID="abcd-1234" TYPE="ext4"
2026-07-24 16:58:14 - Adding entry to /etc/fstab...
2026-07-24 16:58:15 - USB mounted at /mnt/CHATAK_VM
2026-07-24 16:58:16 - Could not parse UUID or TYPE from blkid output.
